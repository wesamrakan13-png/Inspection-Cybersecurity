# 🛡️ Advanced Security Vulnerability Scanner

A powerful, lightweight, and fast security auditing and vulnerability scanning tool built in Python. Designed to help developers and system administrators quickly identify potential security flaws and generate detailed reports.

---

## ✨ Features

- **Fast Scanning Engine:** Scans targets efficiently with optimized performance.
- **Detailed Reports:** Automatically exports scan results into structured **HTML** and **JSON** formats.
- **Lightweight & Easy to Use:** Minimal dependencies, runs smoothly from the command line.
- **Clean Architecture:** Well-structured and organized Python code for easy customization.
